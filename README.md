# De Olho no Mundo

Painel financeiro para acompanhar câmbio, criptomoedas e mercados globais.

## Tecnologias
- Next.js 15
- React 19
- Supabase (integração a configurar)

## Desenvolvimento local
1. `npm install`
2. `npm run dev`
3. Abrir http://localhost:3000

## Estado atual
A interface inicial está pronta. As cotações e os gráficos ainda são demonstrativos; não representam dados de mercado em tempo real. A próxima etapa é ligar fontes de dados reais e configurar a integração segura com o Supabase.

Nunca guardar chaves secretas no código do navegador.
